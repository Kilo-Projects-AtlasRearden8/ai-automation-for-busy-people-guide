Welcome

This is a beginner-friendly guide to four simple automations you can set up today with tools you already have: sorting downloads, renaming files, bill reminders, and saving webpages.

No coding experience needed. Every script is "no-code friendly": copy it, run it, and read what it does. Nothing moves or deletes your original files without you saying so.

The four automations

AutomationWhat it doesTry it
Sorting Downloads Tidy your Downloads folder into Images, Documents, Audio, Video, Archives, Installers, and Other. Read more
Renaming Files Give batches of files clean, consistent names like vacation_2026-10-27_01.jpg. Read more
Bill Reminders See which bills are due soon so you never miss a due date. Read more
Saving Webpages Save a webpage as a single HTML file to read offline — no account, no subscription. Read more

Quick start

  1. Read Safety First before running anything.

  2. Pick an automation and follow its page step by step.

  3. Run the script in dry-run mode (the default) — it shows what it would do without changing anything:

    python3 scripts/sort_downloads.py

  4. When you're comfortable, back up your folder and run with --apply to copy files for real:

    python3 scripts/sort_downloads.py --apply

What you need

  • A computer (Windows, Mac, or Linux)
  • Python 3 (built-in on Mac and Linux; free from python.org on Windows)
  • A web browser (for saving webpages)
  • About 30 minutes
