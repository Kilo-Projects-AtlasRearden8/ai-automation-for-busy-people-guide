# Getting Started

Welcome to *AI Automation for Busy People*. This manual walks you through four
simple automations you can set up today with tools you already have:

1. **Sorting downloads** — tidy your Downloads folder automatically
2. **Renaming files** — give batches of files clean, consistent names
3. **Bill reminders** — never miss a due date again
4. **Saving webpages** — keep pages you want to read later

No coding experience needed. Every script is "no-code friendly": copy it, run
it, and read what it does. Nothing here moves or deletes your original files
without you saying so.

## How to use this guide

- Read the **Safety First** page before you run anything.
- Pick one automation, read its page, and follow the steps.
- Try each script in dry-run mode first — it shows you what *would* happen
  without changing anything.
- When you're comfortable, run it for real.

## What you need

- A computer (Windows, Mac, or Linux all work)
- Python 3 (comes built-in on Mac and Linux; free download from python.org on
  Windows)
- A web browser (for saving webpages)
- About 30 minutes

## Where the files live

```
docs/            Beginner manuals (Markdown)
static/          HTML site you can open in any browser
scripts/         Small Python scripts (dry-run by default)
tests/           Automated checks that prove the scripts work
```
